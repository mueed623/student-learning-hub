
# Student Learning Hub

## Project Description
Student Learning Hub is a responsive mini website
created to provide students with information about
different learning courses.

## Features
- Responsive navigation bar
- Welcome and hero section
- Three course cards
- About Us section
- Show More and Show Less functionality
- Contact form with validation
- Interactive JavaScript buttons
- jQuery slideToggle effect

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery

## Project Structure

mini-website/
- index.html
- css/style.css
- js/script.js
- README.md

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Make sure you have an internet connection
   to load Bootstrap and jQuery.
